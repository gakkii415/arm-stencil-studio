# 3Dタトゥーステンシル

男性・女性の腕、脚、背中へ線を描き、転写用の近似型紙JPGを作る、ブラウザだけで動く作業ツールです。

## 使い方

1. 上部で男性/女性と腕/脚/背中を選びます。モデルごとの図案は画面を開いている間保持します。
2. 黒・水色・オレンジを選び、「描く」で表面を1本指またはペンでなぞります。線幅は0.5〜4 mmの参考値、初期2.5 mmです。
3. どのモードでも2本指のドラッグで回転、ピンチでズームします。指を全て離してから1本指の描画へ戻ります。PCは「視点」でドラッグ、ホイールや＋ / −でズームします。
4. 「消す」で線を消し、「戻す」で描画・消去を1操作ずつ取り消します。
5. 「2Dステンシルに変換」で型紙を作り、iPhone/iPadは「写真に保存」→共有画面の「画像を保存」を選びます。PCはJPGをダウンロードします。

iPhone 16（393 × 852 CSS px）では3D作業領域を高さ663 px確保しています。ツールは下部、モデル選択は上帯、色は描画面内です。3Dと型紙はタブで切り替え、iPad・PCでは幅に応じて並べます。

共有機能が使えない場合は実画像を表示します。長押しして「画像を保存」を選んでください。共有を閉じただけでは保存完了と扱いません。画像は変換時に準備し、保存タップからすぐ共有画面を開きます。

キーボードは B: 描画、E: 消去、V: 視点、Ctrl / ⌘ + Z: Undo。図案やモデルを変更した後は再変換してください。作業内容はページを閉じると失われます。

## モデルと型紙

Blender Studio公式Human Base Meshesの人体スキャン由来の男性・女性を採用しています。筋肉・肘・膝・指・足の形を保持して切り出しました。腕は肩〜手首540 mm、脚は付け根〜足首800 mm、背中は上部〜腰500 mmの参考長さです。手・指・足、背中モデルの胸腹側は表示用です。寸法は人体平均や利用者の実測値ではありません。

腕・脚は巻きつけ型紙を参考に内側の切れ目と肘・膝で2枚に分け、各高さの断面周長に合わせてテーパーをつけます。背中は左右位置と高さを1枚の平面へ写します。厳密な等長UV展開ではなく、曲面や姿勢による局所的な歪みが残ります。

JPGは白背景で色を保持し、腕・背中150 dpi、長い脚はiPhoneの画像サイズ制限を考慮して125 dpiです。型紙ガイドと左右反転を選択できます。反転は図案にだけ適用し、文字は正立します。印刷後に50 mmの目盛を実測し、紙で仮合わせしてから転写してください。印刷ソフトで分割印刷し、必要に応じて切り込みやサイズ調整を行います。

素材はDan Ulrich作・CC0で商用利用・改変・再配布が可能です。出典と加工内容は[素材クレジット](assets/SOURCE.md)に記載します。

## 描画の速度

高密度の人体形状を保ち、BVHで表面位置を検索します。入力をフレームごとにまとめ、3Dは512×1024の専用描画面を更新します。2048×4096の出力用線画は変換時に履歴から生成し、描画中の大きな画像コピーと転送を減らしています。モデルは選んだものだけ読み込み、前のモデルのGPU資源を解放します。

## 開発

Node.js 20以上、Python 3を使用します。

```sh
npm ci
npm run vendor
npm test
npm run dev
```

`http://localhost:4173/` を開きます。実行時に外部CDN、API、サーバー保存、ログインは使用しません。`vendor/` のThree.jsを含む静的ファイルを同一オリジンで配信します。GitHub Pagesはmainのルートを配信するため、ビルドは不要です。

- `assets/*.glb`: CC0の人体スキャン由来の6部位モデル
- `src/models.js`: 性別/部位カタログと参考寸法・断面周長
- `src/arm.js`: 初期腕モデルの互換API
- `src/paint.js`: 表面描画・消去と操作履歴によるUndo
- `src/stencil.js`: 腕・脚の巻きつけ型紙と背中の平面型紙
- `src/touch-controls.js`: 全モードでの2本指回転・ピンチ
- `src/jpeg.js`: JPGの印刷解像度情報
- `src/image-export.js`: iPhoneの画像共有・長押し保存とPCダウンロード
- `src/app.js`: Three.jsと画面操作の接続

Three.js 0.180.0とthree-mesh-bvh 0.9.16はMITライセンスです。両方の許諾文を `vendor/` に保持します。WebGL・Pointer Events・import mapsに対応した現行Safari/Chrome等を対象とします。

## 変更時の必須検査

作業前の完全なコミットSHAを控え、反映前に以下を実行します。

```sh
python3 .github/mandatory.py --base <作業前SHA> --fix
python3 .github/mandatory.py --base <同じSHA>
```

正式バージョンは `index.html` の指定領域にのみ保持します。
