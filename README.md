# 腕専用3Dタトゥーステンシル

3Dの腕表面に黒線を描き、上腕・前腕の型紙へ展開してJPGを書き出す、ブラウザだけで動くMVPです。

## 使い方

1. 「描く」で腕の表面をドラッグします。線幅は0.5〜4 mmの参考値です。
2. 「視点」で回転します。2本指のピンチ、ホイール、＋ / − でズームできます。
3. 「消す」で線を消し、「戻す」で描画・消去を1操作ずつ取り消します。
4. 「2Dステンシルに変換」で型紙を作り、「JPGを書き出す」で保存します。

iPhoneでは3Dと型紙をタブで切り替えます。iPad・PCでは画面幅に応じて両方を並べます。黒線描画と消去は1本指またはペン、回転とピンチは「視点」モードで操作してください。

キーボードは B: 描画、E: 消去、V: 視点、Ctrl / ⌘ + Z: Undo。線画が変わった場合は再変換してください。作業内容は画面を開いている間だけ保持します。

## 型紙の方式と制限

肩〜手首540 mm、上腕280 mm、前腕260 mmの簡易腕モデル1種類を使用します。指・手はありません。成人男性を想定した**参考設定値**で、人体の平均寸法や利用者の実測値ではありません。

腕用の巻きつけ型紙を参考に、内側の縦の切れ目と肘で2枚に分けます。各高さの周長に合わせて幅を変え、線画をテーパー型紙へ写します。厳密な等長UV展開ではなく、楕円断面と中心線の影響による局所的な歪みが残ります。

JPGは白背景・150 dpi、約642 × 360 mm（3792 × 2126 px）。ガイド表示と左右反転を選択できます。左右反転は線画にだけ適用し、文字は正立させます。50 mmの目盛を印刷後に実測し、紙で仮合わせしてから転写してください。印刷ソフトで分割印刷し、必要に応じて切り込みやサイズ調整を行います。

無料3D素材を調査しましたが、単体腕・指なし・直立形状・型紙向けの加工負担を満たす適切な素材を確認できなかったため、簡易メッシュを生成しています。調査根拠は [CONTENT.md](CONTENT.md) に記載しています。

## 開発

Node.js 20以上、Python 3を使用します。

```sh
npm ci
npm run vendor
npm test
npm run dev
```

`http://localhost:4173/` を開きます。実行時に外部CDN、API、サーバー保存、ログインは使用しません。`vendor/` のThree.jsを含む静的ファイルを同一オリジンで配信します。GitHub Pagesはmainのルートを配信するため、ビルドは不要です。

- `src/arm.js`: 参考寸法と腕の生成メッシュ
- `src/paint.js`: 表面描画・消去と操作履歴によるUndo
- `src/stencil.js`: 上腕・前腕の型紙への座標変換
- `src/jpeg.js`: JPGの印刷解像度情報
- `src/app.js`: Three.jsと画面操作の接続

Three.js 0.180.0はMITライセンスです。許諾文を `vendor/THREE-LICENSE.txt` に保持します。WebGL・Pointer Events・import mapsに対応した現行Safari/Chrome等を対象とします。

## 変更時の必須検査

作業前の完全なコミットSHAを控え、反映前に以下を実行します。

```sh
python3 .github/mandatory.py --base <作業前SHA> --fix
python3 .github/mandatory.py --base <同じSHA>
```

正式バージョンは `index.html` の指定領域にのみ保持します。
