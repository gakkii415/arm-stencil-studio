# 腕専用3Dタトゥーステンシル

3Dの腕表面に黒線を描き、上腕・前腕の型紙へ展開してJPGを書き出す、ブラウザだけで動くMVPです。

## 使い方

1. 「描く」で腕の表面をドラッグします。線幅は0.5〜4 mmの参考値で、初期値は2.5 mmです。
2. 「視点」で回転します。2本指のピンチ、ホイール、＋ / − でズームできます。
3. 「消す」で線を消し、「戻す」で描画・消去を1操作ずつ取り消します。
4. 「2Dステンシルに変換」で型紙を作り、iPhone/iPadでは「写真に保存」から共有画面の「画像を保存」を選びます。PCでは「JPGを書き出す」で保存します。

iPhone 16（393 × 852 CSS px）では上下のUIを圧縮し、3D作業領域を高さ663 pxまで広げています。描画ツールは下部に置き、3Dと型紙をタブで切り替えます。iPad・PCでは画面幅に応じて両方を並べます。黒線描画と消去は1本指またはペン、回転とピンチは「視点」モードで操作してください。

共有機能が使えない場合は画像を表示するので、長押しして「画像を保存」を選んでください。共有を閉じただけでは保存完了と扱いません。画像は変換時に準備するため、保存ボタンのタップからすぐ共有画面を開けます。

キーボードは B: 描画、E: 消去、V: 視点、Ctrl / ⌘ + Z: Undo。線画が変わった場合は再変換してください。作業内容は画面を開いている間だけ保持します。

## 型紙の方式と制限

Blender Studio公式のHuman Base Meshesから、人体スキャン由来のリアルな男性の右腕を採用しています。上腕・肘・前腕・手首・指の形を保って切り出し、肩〜手首を540 mmの参考サイズへ合わせています。手・指は位置の目安として表示し、描画と型紙の対象は肩〜手首です。寸法は人体の平均値や利用者の実測値ではありません。

腕用の巻きつけ型紙を参考に、内側の縦の切れ目と肘で2枚に分けます。各高さの周長に合わせて幅を変え、線画をテーパー型紙へ写します。厳密な等長UV展開ではなく、腕の曲面と姿勢の影響による局所的な歪みが残ります。

JPGは白背景・150 dpiで、モデルの周長と長さに沿った画像サイズを使います。ガイド表示と左右反転を選択できます。左右反転は線画にだけ適用し、文字は正立させます。50 mmの目盛を印刷後に実測し、紙で仮合わせしてから転写してください。印刷ソフトで分割印刷し、必要に応じて切り込みやサイズ調整を行います。

素材はCC0で、商用利用・改変・再配布が可能です。元モデルの作者はDan Ulrich。出典と加工内容は [CONTENT.md](CONTENT.md) と [素材クレジット](assets/SOURCE.md)に記載します。描画用の周方向座標を追加していますが、元の筋肉・骨・手の形状は保持しています。

## 描画の速度

腕の高密度形状を保ちながら、BVHで表面位置の検索を速めています。入力をフレームごとにまとめ、3D表示は512×1024の専用描画面を更新します。2048×4096の出力用線画は変換時に履歴から生成し、描画中の大きな画像コピーと転送を減らしています。

## 開発

Node.js 20以上、Python 3を使用します。

```sh
npm ci
npm run vendor
npm test
npm run dev
```

`http://localhost:4173/` を開きます。実行時に外部CDN、API、サーバー保存、ログインは使用しません。`vendor/` のThree.jsを含む静的ファイルを同一オリジンで配信します。GitHub Pagesはmainのルートを配信するため、ビルドは不要です。

- `assets/right-arm.glb`: CC0の人体スキャン由来の腕メッシュ
- `src/arm.js`: モデルに沿う参考寸法と断面周長
- `src/paint.js`: 表面描画・消去と操作履歴によるUndo
- `src/stencil.js`: 上腕・前腕の型紙への座標変換
- `src/jpeg.js`: JPGの印刷解像度情報
- `src/image-export.js`: iPhoneの画像共有・長押し保存とPCダウンロード
- `src/app.js`: Three.jsと画面操作の接続

Three.js 0.180.0とthree-mesh-bvh 0.9.16はMITライセンスです。両方の許諾文を `vendor/` に保持します。WebGL・Pointer Events・import mapsに対応した現行Safari/Chrome等を対象とします。

## 変更時の必須検査

作業前の完全なコミットSHAを控え、反映前に以下を実行します。

```sh
python3 .github/mandatory.py --base <作業前SHA> --fix
python3 .github/mandatory.py --base <同じSHA>
```

正式バージョンは `index.html` の指定領域にのみ保持します。
